# X Liquid Glass icon

The icon master is `icon-master.png`. It was generated with the built-in imagegen tool. The generated transparency is retained in the Chrome icon exports. `npm run build:store` creates the 16, 32, 48 and 128 px icons and updates the Store artwork from that master.

## Generation prompt

Use case: logo-brand / stylized-concept. Asset: the finished app icon for the Chrome extension X Liquid Glass, square 1024x1024, suitable for 128px store icon and 16px toolbar icon. Create ONE premium icon, not a presentation sheet. Center a front-facing dark graphite rounded square tile, occupying exactly 75% of canvas width and height, with genuine transparent outer padding. Within this tile, one very large clean geometric letter X constructed from two broad crossed ribbons of polished liquid glass, subtly beveled, luminous milky glass core with warm amber/champagne refraction on the edges and a faint cool blue highlight. The X has a bold simple readable silhouette; not wispy, not a thin outlined letter. Dark warm charcoal tile with a restrained amber light bloom behind the X, fine rim highlight, gently rounded corners. Material quality should feel like an expertly designed Apple-style liquid glass app icon: elegant, contemporary, optically convincing glass highlights, controlled thickness, no excessive extruded 3D, no perspective tilt. Carefully balanced spacing, strong shape recognition at tiny size. Only the X mark inside the tile; no text labels, no extra symbols, no screen/browser/window mockup, no decorative dots, no documents or stacked cards, no sparkles, no border outside the tile, no giant drop shadow. Deliver the standalone final icon on a transparent background.
