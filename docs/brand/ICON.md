# XGlow icon

The approved icon uses an abstract liquid glass loop with Amber and blue reflections. It contains no letters or platform logos.

The full-resolution source is `icon-master.png`, generated with the built-in imagegen tool. `npm run build:store` exports Chrome icons with transparent padding and opaque 24-bit Store artwork.

## Generation prompt

Use case: logo-brand / stylized-concept. Create ONE premium standalone app icon proposal for XGlow, a Chrome extension that applies a liquid glass visual theme. Square canvas with genuine transparent outer padding. Center a front-facing dark graphite rounded square tile occupying about 75% of the canvas width and height. Inside the tile, a single bold abstract luminous glass loop: an asymmetrical thick toroidal ring, subtly organic like a smooth lens formed from liquid, with a clear open center and one gently folded portion that catches light. The loop must be an original nonrepresentational shape, not a letter, not a logo, not a bird, not a recognizable platform symbol, and not a power button. It should read clearly at 16 pixels and feel memorable rather than a generic collection of shapes. Optically convincing polished glass with a luminous champagne/amber core on the lower left, icy blue refraction on the upper right, rich transparent edges and controlled milky highlights. A restrained light bloom behind the glass on the dark neutral tile. Same premium tactile material quality as a beautifully designed liquid glass app icon: smooth curves, careful bevel, restrained dimensionality, straight-on view, sharp clean silhouette, excellent light/dark contrast. Elegant and minimal but visually striking. No letters of any kind, no X, no G, no text, no branding labels, no sparkles, no extra ornaments, no document/card symbols, no browser mockup, no UI, no perspective tilt, no presentation sheet, no giant drop shadow. Only the abstract glass loop on its rounded dark tile; outside the tile must be actually transparent. This is an icon design proposal for user approval.
